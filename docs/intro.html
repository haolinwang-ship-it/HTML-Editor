The problem

AI-generated HTML is hard to revise.

Beautiful HTML is easy to generate. Editing it as a team — picking the exact paragraph to rewrite, flagging what should change, agreeing on a tweak — is where things break down today.

01

Raw code is too low-level

Non-developers can't safely edit HTML without breaking the layout. They end up screenshotting things and writing "change this".

02

Chat is slow and vague for revision

Every tweak is a full round-trip to the AI. And broad feedback like "tighten this paragraph" or "this section feels dense" has nowhere to anchor.

03

No shared workspace for teams

There's no editor where multiple people can review AI-generated HTML together, see each other's notes, and converge on the next revision.

The solution

A small editor that sits between
your AI and your team.

Humans review and annotate. Then the whole package — edited HTML plus every comment — goes back to the AI as one prompt. One more pass, one more loop.

What it does

The whole loop in one browser tab.

Edit any text inline

Click any piece of text and rewrite it. The HTML framework — tags, classes, styles — stays untouched. Even list markers like "1." or "•" are editable as plain characters.

Add or remove blocks structurally

Click any block (paragraph, card, table row, column) and use the ＋ / ✕ tools to duplicate or delete. Tables get row + column controls. Lists reflow automatically.

Comment on anything

Anchor a note to a single element, multiple elements at once, or the whole document. Useful for abstract feedback ("this section feels too dense") the AI can act on later.

Real-time collab

Share the room link, no signup. Every edit, every comment syncs across all open browsers within ~200ms. Built on Yjs CRDT — works even with flaky network.

Export both ways

Download the edited file as clean HTML for sharing, OR copy a Markdown prompt bundling the HTML and every comment — drop it into Claude / GPT for the next revision. Also downloadable as .md for Claude Projects or NotebookLM.

Under the hood

Boring tech that just works.

No frameworks, no build step on the frontend. The interesting part is how text edits propagate across browsers — that's where Yjs and PartyKit do the heavy lifting.

Frontend
Vanilla JS
Static HTML + ES modules. The editing surface is a sandboxed iframe so user-uploaded styles can't break the app.
Real-time sync
Yjs CRDT
Conflict-free, diff-based text updates. Two people typing in the same paragraph won't clobber each other.
Backend
PartyKit
Cloudflare Durable Objects + WebSockets. Each room is its own object with persisted state.
