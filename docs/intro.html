The problem

But the HTML is rarely right on the first try.

You get a beautiful first draft. Now you want to tweak this paragraph, shorten that list, collaborate with your team. But we found...

01

Editing HTML isn't beginner-friendly

For anyone not comfortable in code, opening the raw file is intimidating. So they screenshot and write "change this" instead.

02

Chat is slow and vague

Chatting with AI again and again is frustrating. And broad feedback like "tighten this paragraph" or "this section feels dense" has no good way to anchor to the right spot.

03

No shared workspace for teams

No editor where reviewers can mark things up together, see each other's notes, and converge on what the AI should change next.

If we don't have one, let's just build one!

What it does

The whole loop in one browser tab.

Edit any text inline

Click any piece of text and rewrite it. The HTML framework — tags, classes, styles — stays untouched. Even list markers like "1." or "•" are editable as plain characters.

Add or remove blocks structurally

Click any block (paragraph, card, table row, column) and use the ＋ / ✕ tools to duplicate or delete. Tables get row + column controls. Lists reflow automatically.

Comment on anything

Anchor a note to a single element, multiple elements at once, or the whole document. Useful for abstract feedback ("this section feels too dense") the AI can act on later.

Real-time collab

Share the room link, no signup. Every edit, every comment syncs across all open browsers within ~200ms. Built on Yjs CRDT — works even with flaky network.

Export both ways

Download the edited file as clean HTML for sharing, OR copy a Markdown prompt bundling the HTML and every comment — drop it into any AI for the next revision.
